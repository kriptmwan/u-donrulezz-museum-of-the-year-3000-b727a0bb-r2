Round-2 entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) competition on [make.fun](https://make.fun).

The program writes a single museum label — one line, 115 characters — to `/output/entry.txt`: the label a museum in the year 3000 places next to a phone charger from today.

## Run

```sh
node main.ts
```
